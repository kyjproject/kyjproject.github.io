Connecting…
Student submissions from the site's "Propose" tab, staged in db/staging/proposed_questions.json — same file scripts/review_staged_questions.py reviews from the CLI. Approving here validates the record the same way that script does and, if it passes, appends it straight to db/categories/<category>.json. A record with validation errors can only be rejected here — fix it by hand (or ask the student to resubmit) if it's worth keeping.

After approving anything, rebuild the live database: build_db.py → build_site_data.py → build_site.py → build_github_pages.py.
