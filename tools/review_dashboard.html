🔎 Question Review Dashboard

Student reports → Connecting…
Run python3 scripts/reports_server.py and open http://localhost:8766/ (the link it prints) to use this page. Click any tile to open a question, then Approve (green), Flag problem (red), or Edit it — editing marks it yellow while the form is open, then green once you save. A small dot on a tile means a student reported that question (see Student reports).

Edits write straight to db/categories/*.json. The pre-built site still needs a rebuild to pick changes up: build_db.py → build_site_data.py → build_site.py → build_github_pages.py. Review status lives in db/staging/review_status.json — it's local bookkeeping, not part of the live site.
