Recommended (works in any browser, including Firefox/Safari): run python3 scripts/staging_server.py and open the http://localhost:8765/tools/add_question.html link it prints, instead of opening this file directly. The page then saves through that local server — no special browser permissions needed.

Chrome/Edge alternative: if you opened this file directly (file://...) in Chrome or Edge, click "Select project root folder" once and pick the repo's top-level folder (the one containing db/ and images/) to grant direct write access instead.

Either way: fill in the fields above, then click "Add to staging" — this appends the record to db/staging/proposed_questions.json (and, if an image is attached, saves it under images/<category file>/<id>.png). Nothing here touches the live database directly. When you're ready, run python3 scripts/review_staged_questions.py to review each staged question and approve/reject it into the real db/categories/*.json files, then rebuild (build_db.py, build_site_data.py, build_site.py, build_github_pages.py).

If neither of the above is available, "Add to staging" instead downloads the full accumulated staging file for this session — replace db/staging/proposed_questions.json with it yourself (an image, if any, downloads separately — move it into images/<category file>/).
